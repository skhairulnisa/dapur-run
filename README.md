# Dapur Run

An interactive grocery checklist — one self-contained HTML page.

Tick what you need, note the quantity and what's still in the kitchen, then print
a clean A4 list or download it as a PDF. A separate **What I Bought** page records
what you actually bought and what you paid, with a running total.

- 163 items across 15 categories, each with a real photograph
- Replace any photo with your own, and add your own items
- Everything is embedded: no internet connection required
- Your list is saved in your browser; **Backup** and **Restore** move it between devices

`index.html` is the whole app. Download it and open it in any browser, or use the
hosted copy.
